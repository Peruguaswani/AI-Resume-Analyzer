# AI Resume Analyzer using n8n

An AI-powered Resume Analyzer built using n8n automation workflows, Gemini API, and email integration. This project analyzes uploaded resumes and generates intelligent feedback automatically.

## Features

* Resume upload and processing
* AI-powered resume analysis
* Automated workflow using n8n
* Email integration for sending results
* Simple automation pipeline
* Easy to customize and extend

## Tech Stack

* n8n
* Gemini API
* Gmail Integration
* JSON Workflows
* Automation Tools

## Workflow Overview

1. User uploads resume
2. Resume data is processed
3. Gemini AI analyzes the resume
4. Feedback/result is generated
5. Result is sent through email automatically

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Peruguaswani/AI-Resume-Analyzer.git
```

### Open n8n

Import the workflow JSON file into n8n.

### Configure Credentials

Add your:

* Gemini API Key
* Gmail Credentials
* Required integrations

### Run Workflow

Execute the workflow and test resume analysis automation.
